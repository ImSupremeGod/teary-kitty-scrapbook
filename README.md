# Teary Kitty Scrapbook

Redesign the existing website to match the cute, intentionally cringey pastel scrapbook aesthetic. Add pink and lavender backgrounds, bows, stickers, doodles, little hearts, cute cat illustrations, Polaroid frames, rounded cards, and playful handwritten-style headings. Make it feel lovingly handmade and funny, not corporate or generic. Keep every existing scene and feature. Do not change the lottery logic or remove any content. Make sure the mobile layout remains clean and readable.
